# Backend Modules

These folders mirror the module boundaries from `docs/solution-blueprint.md`. They are empty by design on the scaffold branch so each feature slice can add code without restructuring the monorepo first.

Current module lanes:

- `Identity`
- `Sessions`
- `Presence`
- `Contacts`
- `Rooms`
- `Messaging`
- `Attachments`
- `Notifications`
- `Administration`
- `XmppBridge`
